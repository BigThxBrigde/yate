## 改进项（3 项，均无阻断）

### 1. Split 不变量检查应使用显式异常而非 assert（可维护性，`yate/session.py`）

**问题**：`remove_node` 中使用 `assert` 检查 split 不变量，Python `-O` 优化模式下会被剥离，数据结构损坏时可能静默失败。

```python
assert len(node.children) == len(node.sizes), "Split invariant broken"
```

**建议**：替换为显式条件检查 + 异常抛出，保证生产环境（即使 `-O`）也能捕获不变量违反。

```python
if len(node.children) != len(node.sizes):
    raise ValueError("Split invariant broken: children/sizes length mismatch")
```

### 2. 消除 `pack/_common.py` 中重复的路径拼接逻辑（可维护性）

**问题**：模块级 `_pkg_path` 与 `SpecInputs.pkg_path` 方法实现完全相同，代码冗余。

```python
def _pkg_path(project_root: str, *parts: str) -> str:
    return os.path.join(project_root, "yate", *parts)

# ... inside SpecInputs ...
def pkg_path(self, *parts: str) -> str:
    return os.path.join(self.project_root, "yate", *parts)
```

**建议**：消除重复，统一单一事实来源（例如仅保留 `SpecInputs.pkg_path`，`collect()` 尽早构造实例）。

### 3. git tag 解析应使用更健壮的分隔符（功能性与逻辑，`tools/changelog/gitdata.py`）

**问题**：`read_tags` 以空格分隔解析 `for-each-ref` 输出；tag 名含空格（罕见但合法）时会解析错误。

```python
name, _, sha = line.strip().partition(" ")
```

**建议**：改用 NUL 分隔：

```python
_TAG_REF_FORMAT = "%(refname:short)%00%(if)%(*objectname)..."
# ...
name, _, sha = line.partition("\0")
```
