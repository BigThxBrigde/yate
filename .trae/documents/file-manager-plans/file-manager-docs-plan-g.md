## 具体修改

### 手册结构（对齐 which-key.en.md 先例：标题+双语链接 → Overview → 分节 → `---`）
1. 标题 + 对侧语言链接；
2. `## 1. Overview`：双形态定位（浮层 vs `--file-manager` 全屏）、三栏说明、
   与 explorer 的关系（共享 Workspace/图标/主题/滚动条）；
3. `## 2. Opening`：`Alt+Shift+F` / `:file-manager` / `yate --file-manager [path]`；
4. `## 3. Keys`：总纲 §六 键位表（P0 导航/过滤视图/多选/退出 + P1 文件操作），
   表格形态与 manual 的键位表一致；
5. `## 4. Selection and switching`：单选/多选语义（Q2 裁决）、切换工作区行为
   （文件→root=父目录；目录→root=目录；dirty 阻塞提示语义——Q1 终裁）；
6. `## 5. Preview`：文本语法高亮/目录子项/二进制占位、缓存与截断
   （FilePreviewConfig 沿用说明）；
7. `## 6. Limitations`：跨形态差异（全屏 q 退出进程）、Windows 属性列降级
   （owner/group `-`）、P2 未做项（hex 预览/排序配置）。

- 中文版为完整翻译（非 `[缺中文]` 占位）；
- 相对路径引用（若引用手册间链接：`./which-key.en.md` 形态）；
- 不写本机路径/绝对路径（doc-conventions §五）。
