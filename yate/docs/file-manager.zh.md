# yate 文件管理器（file manager）

[English](file-manager.en.md) · **中文**

yate 内置一个 lf 风格的终端文件管理器：三栏（父目录 | 当前目录 | 预览）
加一条状态栏，并有两种形态。浮层形态悬浮在编辑器之上，关闭时不触碰
任何编辑状态；命令行启动的全屏形态占据整个界面，选中条目后交给编辑器
接管。未保存的缓冲区永远不会被静默丢弃。

---

## 1. 概述（Overview）

界面由三栏与一条状态栏组成：

* **父目录**（左）——当前目录父目录的列表；在文件系统根显示
  `(no parent directory)` 占位。Windows 上在文件系统根按 `h` 进入
  盘符层，由**中栏**列出盘符（`C:` `D:` …）。
* **当前目录**（中）——可浏览的列表：文件图标、着色目录名、子项数
  徽标（`(12)`，超过上限显示 `999+`）、右对齐的文件大小；被标记的行
  带 `* ` 前缀。
* **预览**（右）——跟随光标：文件显示语法高亮的文本预览，目录显示
  前 100 个子项（见第 5 节）。
* **状态栏**（下）——lf 风格布局：`mode nlink owner group size mtime
  · n/total · 排序提示`；过滤激活时追加 `filter: <query>`，存在标记时
  追加 `marked: N`。平台不提供所有者 / 属组信息时（Windows）降级为
  `-`。

两种形态，同一组件：

* **浮层**——压在编辑器之上的模态浮层（宽 90% / 高 80%）。`Esc` /
  `q` 关闭；下方的编辑器原样还原。
* **全屏**——`yate --file-manager` 直接以文件浏览器启动 yate
  （同一组件，附加 `.fullscreen` 类）。选中条目即切入编辑器主界面；
  `q` 退出进程。

文件管理器与文件树（`:explorer` / `Ctrl+B`）共享同一个 `Workspace`：
隐藏文件、`.gitignore`、`.yateignore` 过滤与 `show_hidden` 开关是同一
份状态；图标、主题配色与细滚动条也随当前主题在两侧同步。

## 2. 打开方式（Opening）

| 入口 | 效果 |
|---|---|
| `Alt+Shift+F` | 打开浮层（vsc 与 vim 两张键位表都绑定了该键） |
| `:file-manager` | 从命令行 / 命令面板打开同一浮层 |
| `yate --file-manager [PATH]` | 以全屏形态启动并定位到 `PATH`（默认当前目录）；与命令行上的位置参数 `PATH` 互斥 |

---

## 3. 键位（Keys）

**导航**

| 键 | 动作 |
|---|---|
| `j` / `Down`、`k` / `Up` | 光标下移 / 上移 |
| `h` / `Left` / `Backspace` | 返回父目录（光标落在来时目录的条目上）；在文件系统根进入盘符层（仅 Windows） |
| `l` / `Enter` / `Right` | 进入目录 / 打开选中集（见第 4 节） |
| `g` `g` / `Home` | 跳到顶部（第二个 `g` 须在一秒内按下） |
| `G` / `End` | 跳到底部 |
| `Ctrl+D` / `Ctrl+U` | 向下 / 向上滚动半页 |

**过滤与视图**

| 键 | 动作 |
|---|---|
| `/` 或 `f` | 增量名称过滤（底部输入框实时收窄列表；`Esc` 清除） |
| `H` 或 `.` | 切换隐藏文件（与文件树同一开关） |
| `s` | 循环排序键：name → size → mtime（目录始终排在最前；状态栏显示当前键与 `asc`/`desc`） |
| `r` / `F5` | 强制刷新（使缓存失效并重新列举） |

**多选**

| 键 | 动作 |
|---|---|
| `Space` | 切换光标条目的标记（光标不动） |
| `v` | 反选全部标记 |
| `l` / `Enter` | 打开选中集（见第 4 节） |
| `Esc` | 两级退出：输入 / 过滤激活时先关闭它，其次清除标记，最后关闭界面 |

**文件操作**

| 键 | 动作 |
|---|---|
| `a` | 新建文件（名称输入在底部输入框） |
| `A` | 新建目录 |
| `R` | 重命名光标条目（预填原名称） |
| `d` | 删除光标条目（输入 `y` 确认；目录以 "directory (recursive)" 显式确认） |
| `y` / `x` | 复制（yank）/ 剪切光标条目进粘贴缓冲 |
| `p` | 粘贴到当前目录（剪切随移动消耗，复制保留；目标同名时粘贴失败并在输入行报 `paste failed:`，先重命名或删除同名项后重试） |

**退出**

| 键 | 动作 |
|---|---|
| `q` / `Esc` | 浮层：关闭并还原编辑器 · 全屏：`q` 退出进程 |

鼠标：单击移动光标，300 毫秒内再次点击同一行即打开，滚轮滚动各栏。

## 4. 选中与切换（Selection and switching）

打开选中集（`l` / `Enter` / 双击）会把标记集合交给工作区切换：

* **无标记**——光标条目单独生效。
* **纯文件集合**——工作区根目录切换为第一个文件所在目录，所有文件
  依次打开为标签页，第一个文件置前。
* **包含目录的集合**（纯目录或混合）——只进入字母序第一个目录
  （工作区只有一个根）；消息行提示
  `multiple entries selected - entering the first directory only`。
* **存在未保存缓冲区**——切换被直接拒绝，消息行警告
  `N unsaved changes - save or discard first`。绝不静默丢弃：先保存或
  关闭已修改的缓冲区，再重新选择。

---

## 5. 预览（Preview）

* **文本文件**使用与 Ctrl+P 面板相同的管线做语法高亮。沿用
  `file_preview` 的限制（`max_lines`、`max_size`；该节的其余键只影响
  面板预览窗），超过行数上限的内容被截断。
* **目录**显示前 100 个子项。
* **降级情形**以暗色提示取代内容：二进制数据显示 `(binary file)`，
  超过大小上限显示 `file too large (> N bytes)`，无法读取显示
  `cannot read: ...`。
* **缓存**——每屏独立保留最近 16 条预览（FIFO），回访条目即时呈现；
  `r` 无论如何都会重读。

---

## 6. 已知限制（Limitations）

* **两种形态的"关闭"含义不同**——浮层中 `q` / `Esc` 弹回编辑会话；
  全屏形态中 `q` 直接退出 yate 进程。
* **未保存缓冲区阻塞切换**——警告即全部交互：不覆盖、也不弹出丢弃
  确认。先保存或关闭缓冲区，再重复选择。
* **Windows 属性列降级**——owner / group 显示 `-`（硬链接数与权限位
  字符串仍正常显示）。
* **双击是计时窗口**——300 毫秒内对同一行的两次点击视为"打开"；
  更慢的连续点击只移动光标。
* **跨卷移动透明处理**——复制 / 剪切 / 粘贴可跨盘符移动条目（内部先
  复制再删除源；大文件无进度显示）。
* **未实现（P2）**——hex 预览、`?` 键位速查浮层、yaterc 可配置项
  （默认排序键、浮层尺寸比例）与状态栏点击排序。
